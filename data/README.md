# Dati

Il dataset non è incluso nel repository per motivi di dimensione.

1. Scarica il dataset da Kaggle:
   https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce
2. Estrai lo zip e copia tutti i file .csv in questa cartella (`data/`).

Dopo questo passaggio gli script SQL e i notebook funzionano senza modifiche.
